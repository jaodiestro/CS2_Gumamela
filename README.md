# Distance between Two Points Calculator

# # The program calculates the distance between two points on a 2d PLANE with the use of input values and a math library.

# # How to run the program? 
-Open program file in VS Code, Replit or Google CoLab.
-Run the program.
-Enter the values for x1, y1, x2, and y2.
-Check the distance which is displayed on the screen.

## Input Needed

- x1

- y1

- x2

- y2

## Sample Output

Enter x1: 2

Enter y1: 3

Enter x2: 7

Enter y2: 8

The distance between the two points is: 7.07
